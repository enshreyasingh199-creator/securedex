# Installation Guide

This guide explains how to install securedex on a windows computer.


## System requirements

Before installing securedex,make sure your computer has:

- Windows 10 or later.
- 4GB RAM
- 2GB available storage
- Internet access
- Administrator permission


## Install securedex

1. Download the securedex installer.
2. Open the downloaded file.
3. Select **Run** if windows ask for permission.
4. Read and accept license agreement.
5. Select **Install**.
6. Wait for the installation to finish.
7. Select **Finish**.

securedex is now installed on your computer.
