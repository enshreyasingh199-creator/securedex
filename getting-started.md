# Getting Started

This guide explains how to get started with securedex


## Before you Begin

Make sure you have:

- A securedex account
- Administrative access
- An active internet connection
- A supported web browser


## Sign in

1. open the securedex login page.
2. Enter your email address.
3. Enter your password
4. Select **Sign in**.

After you sign in, the securedex dashboard appears.


## Next steps

After signing in you can:

- Add a Network.
- Configure security rules.
- View security alerts.
- Manage users.
