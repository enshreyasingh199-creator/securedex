# User Guide

The securedex dashboard allows administrators to monitor network activity and manage security settings.


## Dashboard

The dashboard displays:

- Active securtiy alerts
- Network Activity
- Connected devices
- Security rules status


## View security alerts

1. Sign in to securedex.
2. Open the **Alerts** section.
3. Select an alert to view more information.

Each alert includes:

- Alert Type
- Severity
- Date and time
- Affected Device
- Recommended Action


## Configure a security rule

  1. Open **Security Rules**.
  2. Select **Create rule**.
  3. Enter a name for the rule.
  4. Select the activity or traffic the rule should monitor.
  5. Choose an action.
  6. Select **Save**.

  The new rule becomes active after it is saved.
